BÀI THỰC HÀNH: TRANG GIỚI THIỆU DOANH NGHIỆP BẰNG BOOTSTRAP

Tệp:
- index.html

Cách chạy:
1. Giải nén file ZIP.
2. Mở index.html bằng Chrome.
3. Cần có Internet để Bootstrap CDN hoạt động.
4. Kiểm tra Navbar, Hero, About, Services, Contact, Footer.
5. Thu nhỏ cửa sổ để kiểm tra Navbar trên mobile.

Nộp GitHub:
1. Mở repository dùng cho bài tập HTML/CSS.
2. Chọn Add file -> Upload files.
3. Tải index.html lên.
4. Chọn Commit changes.
5. Sao chép link repository và dán vào CodeGym.
