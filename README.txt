BÀI THỰC HÀNH: BỐ CỤC TRANG WEB VỚI DISPLAY

1. Giải nén file ZIP.
2. Mở thư mục trong Visual Studio Code.
3. Mở index.html bằng trình duyệt hoặc Live Server.
4. Kiểm tra thanh điều hướng có 4 liên kết, phần section có 3 cột inline-block và footer.

Để đưa lên GitHub:
- Mở repository của bạn.
- Chọn Add file > Upload files.
- Tải lên index.html và style.css.
- Chọn Commit changes.
- Sao chép đường dẫn repository và dán vào bài nộp.
