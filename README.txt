BOOKLY — RESPONSIVE BOOK LANDING PAGE

Trang web giới thiệu sách tĩnh có các phần:
- Header / Navigation
- Book Overview
- Author
- Features
- Prices
- Download / Subscribe
- Reader's Say
- Footer

Công nghệ:
- HTML5
- Bootstrap 5.3.3 (CDN)
- CSS tùy chỉnh
- Bootstrap Grid và media queries cho responsive

Cách chạy:
1. Giải nén ZIP.
2. Mở index.html trong trình duyệt hoặc dùng VS Code + Live Server.
3. Cần Internet để tải Bootstrap, Google Fonts và ảnh minh họa từ Unsplash.

Lưu ý:
Đây là trang giới thiệu tĩnh. Form email chỉ hiển thị thông báo minh họa, chưa gửi email hay lưu dữ liệu.

Nộp GitHub:
Tải index.html, style.css và README.txt lên repository của bạn, sau đó sao chép link repository để nộp CodeGym.
