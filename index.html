Nội dung thực hành

SCSS sang CSS bằng Sass CLI

Thực hành biến SCSS, selector lồng nhau, responsive và biên dịch tự động với npm.

Bắt đầu tìm hiểu

1. Node.js và npm

Node.js cung cấp môi trường chạy JavaScript; npm giúp quản lý các package của dự án.

2. Sass CLI

Sass biên dịch tệp SCSS thành CSS để trình duyệt có thể sử dụng.

3. Watch mode

Khi SCSS thay đổi, Sass tự động biên dịch lại CSS tương ứng.
